# TAZLO — Handmade Leather Goods

**Crafted by hand. Made to last.**

TAZLO is a premium handmade leather goods brand focused on timeless design, quality craftsmanship, and durable everyday essentials.

## Features

- Premium editorial-style product page
- Interactive product image gallery with zoom
- Color and size variant selection
- Dynamic pricing and quantity controls
- Add to Bag and Buy Now functionality
- Shopping cart drawer and simulated checkout
- Product details, shipping, and reviews tabs
- Related products carousel
- Responsive design for desktop, tablet, and mobile
- Smooth animations and accessible interactions

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Lucide Icons

## Design

A minimal luxury aesthetic featuring warm ivory, rich leather tones, charcoal typography, elegant layouts, and high-quality product imagery.

## Project Goal

Create a premium, conversion-focused e-commerce experience that showcases handmade leather products through visual storytelling, craftsmanship, and intuitive shopping interactions.
